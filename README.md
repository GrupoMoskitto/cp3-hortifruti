# Painel Multimodal – Hortifruti

CP3 de IA&ML (FIAP – 3ESPA). Sistema web feito com HTML, CSS, JSON e Python (PyScript).

## Funcionalidades
- Catálogo de frutas carregado do `dados.json`
- Busca com guardrails (validação de entrada)
- Telemetria de eventos em tempo real
- Norma e distância euclidiana dos embeddings com numpy

## Como rodar
Abra o `index.html` com a extensão **Live Server** do VS Code.

## Estrutura
- `index.html`
- `src/css/estilo.css`
- `src/python/main.py`
- `src/python/dados.json`
- `src/assets/`
